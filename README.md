# MoviManager

## Descripción

**MoviManager** es una aplicación diseñada para la gestión de películas. Utiliza **Angular** e **Ionic** para ofrecer una experiencia multiplataforma, permitiendo gestionarlista de películas de manera eficiente y moderna.

## Características

- **Visualización de películas**: Permite ver una lista de películas.
- **Interfaz amigable**: La interfaz está optimizada tanto para dispositivos móviles como para escritorio.
- **Tecnologías modernas**: Utiliza Angular e Ionic para asegurar un rendimiento y experiencia óptimos.
  
## Tecnologías Utilizadas

- **Frontend**: Angular, Ionic
- **Lenguaje**: TypeScript
- **Estilo**: SCSS
- **Otras**: HTML, JavaScript

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/KRNGDev/MoviManager.git
2. Navega al directorio del proyecto:
   ```bash
   cd MoviManager
3. Instala las dependencias:
   ```bash
   npm install
